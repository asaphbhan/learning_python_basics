## Home Lab Infrastructure Manager

The main independent project in this repository is a Python-based infrastructure management model.

It uses OOP concepts to represent:

- Devices
- Servers
- Network devices
- Services
- Device relationships and connections
- Status and configuration
- Validation and registries

The project was built as an independent assessment of my OOP understanding and is the foundation for applying Python toward infrastructure automation.

## Learning Approach

The projects were built while following the Bro Code Python course, with additional independent projects used to test whether I could apply the concepts without simply following a tutorial.

The goal is **understanding and implementation**, not collecting completed tutorials.
